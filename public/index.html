How it works

Privacy & data

Your editable skills and saved shortlist remain in this browser. When you analyze a job, the app sends your skills and the job description or URL to its server. The server stores a session-scoped run and its event log for replay. If you submit a URL, the server also requests the external job website.

No job description is sent to an AI API in this release. Skill extraction is a transparent deterministic parser. The overlap percentage is not a prediction of hiring odds. Do not paste sensitive personal information.

For a production deployment, use a persistent Replit database; local SQLite files may not survive redeployment. Analyses are limited to five per hour per session.
